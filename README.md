## LunarArc API

Provides a set of public APIs for interacting with [LunarArc](https://github.com/LunarArcDevs/LunarArc), an experimental hybrid Minecraft server compatibility layer (Forge/NeoForge/Fabric/Quilt with Bukkit/Paper plugin compatibility).

### Usage

Gradle (via [JitPack](https://jitpack.io/#LunarArcDevs/api)):

```groovy
repositories {
    maven { url 'https://jitpack.io' }
}
dependencies {
    compileOnly 'com.github.LunarArcDevs:api:VERSION'
}
```

Replace `VERSION` with a release tag, branch name, or commit hash from this repository.
